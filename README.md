# Calculadora Java
Calculadora de console em Java com menu interativo. 


# Funcionalidades
- 4 operadores matemáticos básicos (soma, subtração, multiplicação e divisão).
- Divisão com tratamento ao dividir um número por zero.
- Menu em loop, até o usuário escolher sair.


# Tecnologias
-Java 21.
- IntelliJ IDEA.


# Como Funciona
- Clone o repositório: `https://github.com/lucasgbarbosag/calculadora-java.git`.
- Entre na pasta: `cd calculadora-java/src`.
- Compile: `javac Main.java`.
- Execute: `java Main`.


# Exemplo de uso

    -----CALCULADORA-----
    1 => Soma
    2 => Subtração
    3 => Multiplicação
    4 => Divisão
    0 => Sair
    1
    Digite o primeiro número:
    2
    Digite o segundo número:
    3
    Resultado: 5.0

- Leitura de dados com `Scanner`
